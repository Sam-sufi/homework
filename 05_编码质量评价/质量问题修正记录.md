# 校园二手交易与物品流转平台质量问题修正记录

本次以团队提交 `9a73602` 为基线，对个人质量分析报告中的六个问题做了修正。该基线已经拒绝姓名为 null 的注册请求；本次补全其他非文本输入的校验。下表中的编号沿用原报告。

| 编号 | 修正内容 | 验证结果 |
| --- | --- | --- |
| Q01 注册姓名 | 文本字段先校验字符串类型，再去除首尾空白并检查长度。 | 以空值、数组和数字注册均返回 400，数据库未新增该用户。 |
| Q02 商品金额 | 发布和编辑商品时，将无穷大导致的金额转换异常归入输入错误。 | 提交字符串 Infinity 返回 400，数据库未生成该商品。 |
| Q03 管理员决定 | 商品审核、撤回审批、争议裁定均要求提交 JSON 布尔值。 | 管理员提交字符串 false 审核商品时返回 400，商品保持待审核。 |
| Q04 收藏重试 | 商品详情返回当前用户的收藏状态，按钮发送目标状态。收藏使用唯一键去重，取消只删除本人的记录。仅传商品编号时默认收藏。 | 连续收藏两次仍只有一条记录，连续取消两次后记录数为零。两组操作后，详情状态和收藏列表一致。 |
| Q05 下单通知 | 下单与待投递通知一起提交。收件人打开“我的”时，系统在另一个事务中投递并移除待办。失败保留待办，下次打开时重试。 | 强制通知写入失败后，订单仍存在，商品为已预订。排除故障后连续打开收件箱两次，始终只有一条通知。 |
| Q06 撤回审批 | 只在批准撤回时要求订单处于待交付或已完成。管理员可以驳回已转入争议的订单所关联的待审核申请。 | 申请变为已驳回，订单保持争议处理中，买家的确认时间保持原值。 |
