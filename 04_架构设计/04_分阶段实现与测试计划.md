### 1.1 S1 详细退出条件

- [ ] 新用户注册（学号 8–12 位）→ 登录 → 刷新页面仍在线；
- [ ] 发布缺字段被拒、合法发布进入"待审核"、"在售"商品不可直接改；
- [ ] 管理员审核通过后在列表出现，驳回后卖家可见原因并重提；
- [ ] 未登录访客不能收藏/咨询；第三人读不到他人咨询；
- [ ] 证据：TC-01～03、TC-10 的原始输出 + 一次人工页面走查记录。

### 1.2 S2 详细退出条件

- [ ] 同一商品 20 个并发下单只有 1 单成功，其余收到 409；
- [ ] 单方确认后订单仍"待交付"，第二方确认后变"已完成"且商品"已售出"；
- [ ] 单方确认后普通取消被拒；2 小时内可提交撤回申请，管理员批准后转争议；
- [ ] 评价一次、可追加、可回复、评分平均计算正确、非 PNG/JPEG 被拒；
- [ ] 证据：TC-04～09、TC-13/14 输出；并发用例的线程数与成功数记录。

### 1.3 S3 详细退出条件

- [ ] 封禁账号可看订单、可确认交付、不能发布/下单；
- [ ] 冻结商品不出现在检索与详情（管理员与卖家除外），解冻后按状态恢复；
- [ ] 统计只把"已完成"计入完成数与成交额；
- [ ] 争议认定完成必须有至少一方确认 + ≥10 字说明，管理员不能代签；
- [ ] 每条管理员处置在 `audit` 中可查；
- [ ] 证据：TC-11/12/15/16/18 输出 + `audit` 抽样截图/导出。
