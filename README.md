# 校园拾集 —— 校园二手交易与物品流转平台

面向校园闲置交易的本地 Web 应用：学生发布物品、管理员审核、买家下单占用、线下交接后双方确认，
并支持收藏咨询、评价举报、争议处理与数据统计。课程《软件工程》完整项目。

**零第三方依赖**：后端只用 Python 标准库，数据存 SQLite，前端是原生 HTML/CSS/JS，不需要 pip、Node 或数据库服务。

## 快速开始

```bash
cd 完整项目
python run.py            # 或双击“启动系统.bat”
```

浏览器打开 <http://127.0.0.1:8000>。

- 端口被占用：`python run.py --port 8001`
- 首次启动自动执行 `schema.sql`、创建 `data/campus.db`，并写入 3 个演示账号与 6 件在售商品
- 已有数据时不会覆盖；删掉 `data/` 目录即可恢复到初始演示数据

## 功能一览

- **用户**：学号注册、密码加盐散列（PBKDF2）、登录/退出、连续 5 次失败锁定 5 分钟
- **商品**：发布与编辑、PNG/JPEG 照片上传、管理员审核通过/驳回、下架、冻结与解冻
- **检索**：关键词、分类、价格区间，按发布时间/价格/卖家评分排序
- **互动**：收藏与取消、商品关联的私有咨询、站内通知
- **交易**：下单即占用（先到先得）、卖家接单或拒绝、取单释放占用、双方分别确认交付
- **售后**：评价（可修改并保留历史）、举报与处理结论、2 小时内撤回确认、争议裁定
- **后台**：用户封禁（≥7 天）、商品治理、举报/撤回处理、按时间区间统计并导出 CSV

## 目录结构

```
完整项目/
├─ app.py               启动入口：建库 + 启动 HTTP 服务
├─ api.py               HTTP 层：路由、鉴权、CSRF、统一响应
├─ services.py          业务层：22 个动作函数 + act() 分发
├─ db.py                数据层：连接、建表、种子数据、统计
├─ core.py              工具层：时间、密码散列、校验与异常
├─ run.py               命令行入口（--port）
├─ 启动系统.bat          Windows 双击启动
├─ schema.sql           13 张表 + 2 个唯一索引
├─ backup.py            数据库在线备份（输出到 data/backups/）
├─ static/              前端页面：index.html / app.js / style.css
├─ tests/test_app.py    12 项 HTTP 集成测试
├─ docs/screenshots/    界面截图
├─ data/                运行时生成（campus.db，已忽略，不提交）
└─ README.md            环境清单 + 系统说明（详细版）
```

请求流向：`static/app.js → api.py（认人、鉴权、路由）→ services.py（业务规则）→ db.py（SQL）→ SQLite`。

## 测试

```bash
cd 完整项目
python -m unittest discover -s tests -v
```

12 项集成测试覆盖：注册认证与 CSRF、发布审核检索、私有咨询、并发下单、取消释放、确认幂等与评价历史、
撤回审批与统计、撤回超时驳回、冻结封禁期间履约、举报审计导出、异常回滚、争议关闭与图片校验。
测试使用临时数据库与随机端口，**不会影响 `data/campus.db`**。

## 数据与备份

- 所有业务数据保存在 `data/campus.db`
- 备份：`python backup.py`，输出到 `data/backups/`（SQLite 在线备份，无需停服务）
- 恢复：停止服务后，用备份文件替换 `data/campus.db`

## 范围说明

本版为单校园、单件库存、线下交付与线下结算的课程实现：认证使用本地学号 + 密码（不接真实身份系统），
照片单张、咨询与评价为文字，管理员为单层角色；不包含在线支付、资金托管、物流、借用归还与跨校交易。
默认只监听本机，公网部署需另行配置 HTTPS 与真实认证接口。
